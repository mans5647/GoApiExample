
# 🐍 Snake Maze API

Это серверная реализация пошаговой игры в лабиринте, где игрок управляет змейкой с помощью HTTP-запросов. Игрок начинает в стартовой точке и должен найти путь к выходу, избегая стен.

---

## 📦 Стек технологий

- Go
- Gin (HTTP-фреймворк)
- REST API

---

## 🚀 Запуск

1. Убедитесь, что установлен Go (версии 1.18+)
2. Склонируйте репозиторий
3. Установите зависимости:
   ```bash 
   go mod tidy
   ```

4. Запустите сервер:

   ```bash
   go run .
   ```

Сервер будет доступен по адресу: `http://127.0.0.1:8080`

---

## 🎮 Игровой процесс

* Игрок начинает в клетке `(1,1)`
* Цель — добраться до клетки с кодом `999` (выход)
* Карта лабиринта зашита в код и представляет собой матрицу `11 x 22`
* Доступные клетки:

  * `1` — можно двигаться
  * `0` — стена
  * `999` — выход

## 📡 Эндпоинты API

### 🔀 Движение змейки

**GET /maze/move?where={direction}**

Параметр `where`:

* `0` — вправо
* `1` — влево
* `2` — вверх
* `3` — вниз

**Пример запроса:**

```
GET /maze/move?where=0
```

**Пример ответа:**

```json
{
  "Walked": true,
  "Where": 0,
  "Exit": false,
  "CurrentLocation": {
    "Row": 1,
    "Column": 2
  }
}
```

---

### 👁 Получение информации о текущем положении

**GET /maze/myloc**

Возвращает информацию о количестве стен вокруг и направлениях, в которые можно двигаться.

**Пример ответа:**

```json
{
  "WallCount": 2,
  "DirectionsAvailable": 13
}
```

`DirectionsAvailable` — битовая маска доступных направлений:

* `1` — влево
* `4` — вправо
* `8` — вверх
* `16` — вниз

Например, `13` = `1 + 4 + 8` = влево, вправо и вверх

---

## 📐 Внутренние структуры

* `maze` — фиксированная матрица лабиринта
* `Position` — структура позиции игрока (строка, колонка)
* `Move()` — логика перемещения
* `LookAround()` — логика определения доступных направлений
